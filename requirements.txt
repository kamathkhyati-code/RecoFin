# Minimal dependencies for demo_app.py specifically (Streamlit Community
# Cloud deployment). The full dev environment (langchain, langchain-groq,
# etc.) is declared in pyproject.toml and installed via
# `pip install -e ".[dev]"` -- demo_app.py doesn't need any of that, so
# this file stays deliberately separate and minimal rather than reusing
# the full dependency set, to keep the Cloud build fast and reliable.
#
# demo_app.py now calls the real build_graph() (recon_platform.graph.build),
# which pulls in langgraph directly and chromadb transitively (via
# reasoning.memory.match_memory's module-level MatchMemory singleton).
# Traced by installing only the base set below in a clean venv and
# resolving each ModuleNotFoundError one at a time -- langgraph-checkpoint-
# sqlite is NOT required (demo runs without a checkpointer).
#
# langchain-groq: only imported lazily, inside GroqLLMGateway.__init__,
# when GROQ_API_KEY is actually configured in this deployment's secrets
# (see demo_app.py's _build_gateway) -- without a key, gateway stays None
# and this import path never runs. Included here so the gateway path
# works the moment a key is added, rather than needing a second
# requirements.txt fix.
streamlit
pandas
pydantic
httpx
paramiko
langgraph
chromadb
langchain-groq
